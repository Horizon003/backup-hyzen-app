## Contributions

Only contribute code or artwork you are authorized to license. If the ownership or origin of an asset is unclear, open an issue before importing it. Avoid committing real student data, copyrighted textbooks, private documents, credentials or unreleased client material.

For questions about permission to reuse a branded asset, contact the repository maintainer through the available GitHub channels.
